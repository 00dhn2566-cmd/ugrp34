## 2. yaw 권한 한계

```
호버 로터 속도  n0 = 56.5 + 44.4·m_pkg = 100.9 rev/s   (parameters.m 추력 바이어스)
limit_yaw = 20 전개 →  n = 80.9 / 120.9 rev/s
Q = cq·ρ_air·n²·D⁵   (plant_sim.py 상수)
τ_max = 2·[Q(120.9) − Q(80.9)] ≈ 0.317 N·m
```

| 외란 | 권한 점유 | 관측 |
|---|---|---|
| 0.01 N·m | 3.2 % | 지속 시 정상편차 7.68° (적분 배율이 잘 듣는 영역) |
| 0.10 N·m | 31.5 % | 3 s 돌풍에 yaw 279° 이탈 |
| 0.30 N·m | 94.6 % | 출력 완전 포화 — 게인·적분 무관, 25 s 내 미정착 |

**부수 발견 (미해결)**: C++ `mixYaw = {-1,+1,-1,+1}` × `mixDir = {+1,-1,-1,+1}` 로 계산하면
반토크 1차항이 상쇄돼 `τ_max = 0` 이 나온다. yaw 열을 `±SPIN_DIR` 로 놓아야 0.317 이 나오고
그래야 0.3 N·m 포화 실측과 맞는다. **C++ 믹서 yaw 열이 틀렸을 가능성** — 08-18 골든 확정은
x/y 런의 roll/pitch 상관이라 yaw 열은 미검정. → NEXT.md 참조.

```
자세 경로 여유 : 10~20 ms      ← kd −127.5 / filtD 2500 고이득 미분이 원인
위치 경로 여유 : 0~50 ms       ← 해상도 부족, 미세 스윕 필요 (chain g 중단됨)
```

**교차 검증**: `capability` 의 지연 규칙 `v ≤ 0.5·track/τ` 을 1 kg 공칭 v=1.2 로 뒤집으면
`τ ≤ 16.7 ms`. 추종 예산에서 나온 값과 위상 여유 실측(10~20 ms)이 독립적으로 같은 자리를
가리킨다 — 규칙이 우연히 맞은 게 아니다.

**실기 함의**: IMU 직결 1~3 ms 는 여유 안. 그러나 **모터 추력 응답 20~40 ms** 와
**VIO 30~100 ms** 는 이미 한계 밖 → 실기 전 자세 루프 재튜닝 필요.

## 6b. ★ 폐루프 오버슈트 vs 순항 속도 (08-22 실측)

재현: `matlab -batch "cd(<모델폴더>); addpath('diagnose'); sweep_overshoot_speed"`
조건: 3 m 직선(레이즈드 코사인), 이동시간만 바꿔 피크 속도 스윕, 외란 없음, 짐 1 kg, 투하 무력화.

| 이동시간 | v 피크 | **오버슈트** | 최대이탈 | 정착 |
|---|---|---|---|---|
| 10.0 s | 0.471 m/s | **0.91 cm** | 0.91 cm | −0.63 s |
| 6.0 s | 0.785 | **2.39 cm** | 2.39 | 0.19 |
| 4.0 s | 1.178 | **4.93 cm** | 4.93 | 0.48 |
| 3.0 s | 1.571 | **8.04 cm** | 8.04 | 0.60 |
| 2.4 s | 1.963 | **11.55 cm** | 11.55 | 0.65 |

**적합: 오버슈트 ≈ 3.13 · v²  [cm, m/s]**  (v² 법칙이 5점 전부에 잘 맞는다)

| 목표 | 허용 순항 속도 |
|---|---|
| 5 cm 이하 | **v ≤ 1.264 m/s** |
| 3 cm 이하 | **v ≤ 0.979 m/s** |
| 2 cm 이하 | **v ≤ 0.800 m/s** |

**해석**
- 최대속도 부근(v≈2.0)에서 **11.6 cm**. 문서의 20.6~22.9 cm 보다 작은데, 그쪽은
  고도 스텝/1 m 한계가속처럼 더 공격적인 조건이라 그렇다. 경향은 같다.
- **오버슈트는 순항 속도만으로 거의 결정된다** (거리·시간이 아니라). 운동에너지 ∝ v² 이니
  물리적으로 맞는 모양이다.
- 현 `capability` 1 kg 공칭 `v = 1.2 m/s` → 예상 오버슈트 **4.5 cm**. 이미 "수 cm" 안이다.
  **사용자가 본 30 cm 는 `agile` 프로파일이나 한계 가속 조건일 가능성이 높다.**
- 그래서 조치는 간단하다: **`capability.limits.v` 를 목표 오버슈트에서 역산해 정하면 된다.**
  별도 제어기 손질 없이 스펙 한 줄로 끝난다.
