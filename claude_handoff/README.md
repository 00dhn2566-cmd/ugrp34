# claude_handoff — 세션 인계 폴더 (Claude 전용)

**새 세션은 여기 가장 최근 날짜 폴더부터 읽으세요.** 다른 컴퓨터·다른 모델로 이어받아도
그 폴더 3장만 보면 문맥이 복원되도록 씁니다.

```
claude_handoff/
├── README.md          ← 이 파일 (규약)
└── YYYY-MM-DD/
    ├── SESSION.md     ← 그날 무엇을 왜 했나 + 틀렸다가 정정한 것
    ├── FINDINGS.md    ← 실측 수치와 재현 명령 (숫자의 출처)
    └── NEXT.md        ← 남은 일: 우선순위 · 근거 · 착수 방법
```

## 다른 문서와의 관계

| 문서 | 성격 | 누가 읽나 |
|---|---|---|
| `control_seoungjin/SESSIONS_BOARD.md` | **한 줄 기록의 시간순 원장** — 사건마다 누적 | 사람 + Claude |
| `claude_handoff/<날짜>/` | **그날의 인계 묶음** — 문맥 복원용, 요약·정정·다음 일 | Claude (우선) |
| `control_seoungjin/docs/*.md` | 주제별 설계·검증 문서 (영구) | 사람 |
| `control_seoungjin/INTERFACE_SPEC.md` | 규격 (계약) | 사람 + 상위 프로그램 |

보드는 "언제 무슨 일이 있었나", 여기는 "지금 이어받으려면 무엇을 알아야 하나"입니다.
겹쳐도 됩니다 — 여기 쓴 내용은 보드에도 한 줄로 남깁니다.

## 쓰는 규칙

1. **정정을 반드시 적는다.** 세션 중 틀렸다가 뒤집은 결론은 그 자체가 인계 대상입니다.
   ("A가 원인인 줄 알았는데 B였다" 를 안 적으면 다음 세션이 같은 길을 다시 갑니다.)
2. **숫자에는 재현 명령을 붙인다.** 출처 없는 수치는 다음 세션이 못 믿습니다.
3. **미완은 미완이라고 적는다.** 되는 것처럼 쓰지 않습니다.
4. 날짜 폴더는 만들되 **과거 폴더는 고치지 않습니다** (그때의 판단 기록).
