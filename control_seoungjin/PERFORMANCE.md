## 1. 시스템 구성

### 1.1 플랜트 (Simscape Multibody, `Models/quadcopter_package_delivery.slx` 구운 모델)
- 기체 FX450 CAD 실측 관성, 로터 4개 `Aerodynamic Propeller`(Simscape Driveline, K_thrust 9.79 / K_drag 0.597 앵커), 모터 1차 동역학, `Wind and Drag`(상수풍·항력).
- 짐: 0.14 m 정육면체, 밀도로 질량 설정, 현수(케이블) — 진자 모드 **~1.8 Hz**(1 kg). 기체 건조 질량 1.2726 kg, 1 kg 탑재 총 2.2726 kg, 호버 회전수 100.9 rev/s(17차 골든).
- 무하중(0 kg)은 CG가 추력면 아래 8.1 cm → 위 0.8 cm, 자세 관성 1.71→0.93e-2 kg·m² — 물리적으로 다른 기체(§6).

### 1.2 제어 구조 (캐스케이드 PID, Simulink 원본 = C++ `controller_cpp` 이식 골든 일치)
```
미션 JSON → path_time(시간 부여) → 스무더(물리 포락선 v/a/j) → ZVD 셰이퍼(1.8 Hz, 대역 1~3 Hz) → 게이트(v/a/j/snap) → trajectory.mat
  → 위치 PID (x/y/z, posErrSat 클램프, tilt 한계) → 자세 PID (roll/pitch, kd 필터 filtD, 출력 클램프 limit_att) → yaw PID
  → 믹서 + FF 호버 트림(bias_hover_rps ∝ √총질량) → 모터 내부 루프 → 플랜트
```
- 자세 PID 게인은 **음수**(플랜트 u→각가속 이득 음수). 자세 측정 필터 0.05 s(마스크 `altitude_filtM`이 roll/pitch 필터에 배선됨), z 측정 필터 `Filter pz`(질량 스케줄).
- 프로파일(INTERFACE_SPEC §1 `controller_profile`): **precision**(기본, kp_pos 8/kd 3.2 @1 kg) / balanced(12/4.8) / agile(24/10.8 @1 kg, z는 8/3.2). 상위 계층이 임무별 선택.

## 9. 정직한 한계와 처방
1. **yaw 루프 느림**(Y1 2.1 s): 의도적 완만 설계, 위치 무해. 대역폭/댐핑 재조정 → ★튜닝 세션.
2. **0 kg 외란 강건성**(R2/R3 ❌): 호버 정밀과 동시 만족 게인 없음(sA 0.5: 15.5°/46 cm이나 호버 0.56°). 임무상 무하중 비행은 운용 밖(투하 없음) → 생존 스펙; 실기는 **배터리 저장착으로 0 kg 상태 제거**(0.5 kg이면 1 kg 스펙 전부 통과) 권고; 필요 시 임무별 sA 선택.
3. **이륙 새그**: 1 kg 5.0 cm 경계, **2 kg 8 cm 초과** → 2 kg 튜닝 1순위(sZ/altCmdSat/FF).
4. **미측정**: 자세 스텝 응답(R1~R3, R9) 하네스 미구축; 2 kg 초과 한계(M5).
5. **시뮬 한정**(이상 센서, 구운 모델): 실기 이식은 C++ 골든 트레이스(MATLAB ↔ `qc_trace`, RMS ≤2 % FS)와 파라미터 추정기(`estimate_params.py`)로 관리. C++는 질량 스케줄까지 동기됐으나 이 머신 컴파일러 부재로 **미빌드**(★).
6. 0.1 m 위치 스텝의 49 % "오버슈트"는 성형기 오용 경로(기준 궤적 출렁임)이지 컨트롤러 성능이 아님.
