## 재학습 스펙 초안 (우선순위)

1. **가림 창문 라벨 정책 확정** (규격 §4 공백 — 회의/비동기 합의 필요): 창문-창문 가림 corner를 visibility=0으로 마킹(정책 C와 통합) 또는 고가림 창문 라벨 제외. 임무 관점 근거: 순서상 뒤 창문은 앞 창문 통과 후 관측되므로 가림 상태 검출은 과요구. **이 정책 없이 재학습하면 미검출의 61%는 그대로 남는다.**
2. **2차 데이터셋 증강**: 겹침 시나리오(같은 색 겹침 포함)·저대비(창문↔벽 색 근접)·화면끝 절단 + **조명 랜덤화 버그 수정 후** 생성 (윤호 렌더러 `brightness/direction`→`intensity/azimuth_rad` 키 불일치 — 감사 보고 참조).
3. **imgsz=960** — 원거리 소형(저신뢰군) 대응. 1·2 없이 단독 실행 시 기대 효과는 미검출 39% 일부와 꼬리 소폭.

부수 효과: 1번 정책은 HSV 겹침 오판 19건(2026-08-02 검증에서 발견, 같은 뿌리)과 평가 매칭 경합도 함께 정리한다.
